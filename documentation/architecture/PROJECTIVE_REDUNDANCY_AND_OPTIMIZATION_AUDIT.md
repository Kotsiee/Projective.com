## 1. Executive summary

**The architecture's load-bearing walls are holding. The waste sits at the edges.**

- **What holds:**
  - **Islands:** none touches the database.
  - **Fees:** every fee preview goes through the shared helpers.
  - **HNSW:** the pgvector index is used correctly.
  - **"No Hold, No Work":** has one pure client mirror.
  - **`?tkv=`:** has one host island.
  - **Overlays:** none is a shadow modal or drawer.
  - **Fields:** 85–90% of field controls go through `@projective/ui/fields`.
- **Where the waste is:**
  - **CSS:** feature-level CSS re-skins the system rather than consuming it.
  - **Menus:** most menus are hand-built.
  - **Formatting:** one ticket money formatter silently prints dollars.
  - **Read path:** the hot read paths fan out the same queries several times per request.

## 2. Method, scope and premise corrections

**Method.**

- Four parallel sweeps covered shadow primitives, cards/tagification/tokens, money and lifecycle
  duplication, and the read path. Each candidate was confirmed by reading the code, and false
  positives were discarded.
- I spot-checked the High rows myself: undefined tokens, `formatTicketMoney`, the wallet fan-out,
  the inbox tail loop, the GoTrue call, the FX cache order, `ArcCache.through`, the quote parser,
  and the `ServiceModifier`/`SiteHeader` listeners.
- Counts come from `rg`/`grep` with comment lines filtered out. The exact commands are in the
  working notes behind each table.
- Nothing was run against a database or measured in a browser. Request counts are derived from the
  code, not traced.

**Exemptions honoured, so these are not counted as violations:**

- **Landing:** `features/landing/**`, `/` and `/features` under Decision #280.
- **App modals:** the 10 "app modals" that assemble the overlay hooks (DS §B.10.1).
- **Split-pane modals:** they await the §F.5 ruling.
- **Focus rings:** the owner's removal of focus rings (commit 152a27a, with exceptions under #171,
  #176 and #285).
- **Never-converted figures:** landing and about pages, under #277, #281 and #301.
- **Pinned currency:** business rows that pin `displayCurrency` (#248).

**Premise corrections.** The brief that commissioned this audit made these claims; this is what the
code and docs actually say.

| Brief said                                         | Actually                                                                                                                                                                                              |
| :------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Use `withCache` with TTLs                          | `withCache` exists only as a sample in SA. The real primitives are `core/cache.ts` (`ArcCache`, tenant-scoped, per isolate) and `core/kv.ts` (`openSharedKv`).                                        |
| The stage fee is "adjusted by Standing"            | `finance-model.md` §16.4 says it is **not**. Only the marketplace commission tapers. This is already flagged as #337 X4, so it is not re-flagged here.                                                |
| Active rows must be solid `--surface-2`            | §B.4.2 bans translucent fills only on nav-rail items, middle-nav rows and tags. Decision #330 logs the neutral `--tint` active fill as an exception (flag a).                                         |
| Flag bare `:focus` and focus-ring inconsistencies  | Focus rings are removed app-wide by owner directive (`apps/web/styles/global.css` §"NO VISIBLE FOCUS INDICATOR"). Per-selector findings are therefore mostly moot. The policy itself is raised as Q3. |
| `@projective/ui/overlay` primitives (Modal, Sheet) | There is no `Modal`, `Sheet` or `Segmented` export. The real names are `Dialog`, `Drawer` (`position`) and `SelectButton`. The exported `Overlay` fails the `BodyPortal` gate and has 0 consumers.    |
| The `.ui-hit` 24px floor                           | `.ui-hit` is used by only 4 field controls. Checkbox, Radio, Switch and the steppers read `--fld-hit` directly. The floor is the same; the mechanism differs.                                         |
| Islands may import Supabase                        | **None does.** No island imports `@supabase/supabase-js`, `createClient`, `getUserClient` or a runtime `@server/` module. M3.2 passes.                                                                |
| The "7-day safety window"                          | `pending_release_days = 7` is correct (#191), but the value never reaches the client. Every "7" in the UI is a literal (L-15).                                                                        |

## 3. Findings

Severity is defined by user impact, not by which gate was broken:

- **High:** a user-visible defect, a money path, an accessibility failure, or an O(n) cost on a hot
  path.
- **Medium:** a merge-gate violation or duplicated behaviour.
- **Low:** drift or polish.

The **Category** column uses the four categories the brief asked for, plus **Logic Duplication** for
M2.

## 5. What is healthy, and should be protected

- **Islands are dumb:** 0 database access across 219 islands.
- **Fee previews go through shared helpers** (`platformFeeFor`, `stageCostCents`,
  `ticketTotalCents`), so a preview equals the charge (#187).
- **`ArcCache`'s tenant rule is enforced by its types.** A global key cannot be produced by
  omission. Every Missing Cache remediation above respects it, and public data uses the explicit
  anonymous tenant.
- **Currency resolution is request-scoped** through `AsyncLocalStorage`
  (`apps/web/utils/currency-context.ts`), with the JWT claim read first. This is the model the other
  chrome reads (D-07/D-10/D-11) should copy.
- **Overlays:** every dialog, drawer and tooltip goes through the package or its sanctioned hook
  tier.
- **pgvector:** `fn_nearest` uses the HNSW index with the correct operator class (`vector_ip_ops`
  and `<#>`).
- **Keyset pagination exists** where it matters most: the message feed and the wallet `list_ledger`.
