| 92 | **Button tactile feedback, and the `--on-primary` contrast defect fixed at the token layer (2026-09-07).** A press-feedback model for every pressable control, and the closure of the defect flagged and routed around across Decisions #64 / #65 / #74 / #76 / #77 / #78 / #79. **(A) THE INVARIANT COULD NOT BE SATISFIED AS BRIEFED, and measurement is what settled it.** The brief asked for both "lock primary ink to `#FFFFFF` / `P.tone(98)`" and "dark mode must never drop below 7:1". Those are mutually exclusive against this theme: white on dark `--primary` (`#00929e`) measures **3.75:1**, and the token pair measured **3.57:1**. For white to clear 7:1 the fill needs a luminance ≤ 0.10, which on a near-black page (`--bg` is tone 2) is a button that has to be hunted for — a dark page forces a light fill, and a light fill forces dark ink. There is no third arrangement, so the INVARIANT was implemented and the prescription was not (the Decision #70(a) precedent: the tokens a brief names are used, the literals it names are not). **(B) THE ROOT CAUSE, and a worse number than anyone had recorded.** `theme-engine.ts` set dark `--primary: a1.tone(fg(55))` / `--on-primary: a1.tone(on(98))` — both tones ABOVE mid — violating the file's own stated invariant that a colour and its `on-` pair must straddle it, with the comment directly above describing code that was not there. Beyond the known 3.57:1: because `fgTone` widens a fill UP in dark mode while `onTone` widens an `on-` role DOWN, the two **converged** under `data-contrast="high"` and measured **1.75:1** — the accessibility overlay made the product's most-used control unreadable, the exact inverse of its job. **RESOLVED BY MODE-INVARIANCE, not by straddling (product owner, 2026-09-07).** The first fix straddled the dark pair (`fg(80)`/`on(20)`, 7.74:1) at the cost of the brand reading as a different colour in dark mode; the owner ruled that `--primary` is core brand identity and must be **strictly identical across themes**. Identical source, different brand, in the one state a struggling reader opts into. Raw tones remove the mode input entirely.
